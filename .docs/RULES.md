# 开发规则 - RULES.md

## 代码规范

- AutoJs6 源码优先使用 ES5 兼容写法：`var`、普通函数和 CommonJS。
- 注释统一中文，说明设计原因和安全边界。
- 命名表达业务含义，禁用 `data`、`temp`、`x` 等无意义名称。
- 图片对象由创建它的模块负责 `recycle()`。
- 所有轮询、重试和业务循环必须有明确上限。

## 分层规则

- `core/`：日志、截图、动作、等待、流程和运行时，不知道具体游戏。
- `config/`：项目名、包名、输出目录和设备基础配置。
- `tasks/`：页面识别、坐标、阈值和完整业务流程。
- `assets/`：视觉模板及其采集说明。
- `entry/`：只负责选择任务并调用运行时。

录制或采集结果必须先变成任务配置，执行逻辑不能依赖临时 UI 状态。

## 任务规则

- 一个任务完成一条业务流程。
- 动作前识别当前页面，动作后验证目标状态。
- 状态未知时抛出异常，由运行时统一截图和记录。
- 坐标操作必须检查设备分辨率或使用明确的适配策略。
- 新任务复制 `_task-template-autojs.js`，完成后登记到任务表。

## 仓库规则

- 禁止硬编码密钥、账号、设备口令和云机地址。
- 禁止 `--no-verify`。
- AutoJs6 产品代码放在 `src/`；维护脚本放在 `.docs/script/`。
- 修改通用入口或模块后执行 `npm run check` 和 `npm run build`。
- 生成的 `dist/` 不提交 Git。

## 文档规则

- `HANDOFF.md` 只保留 next action、当前状态和最近迭代。
- HANDOFF / RULES / PROJECT 任一超过 4000 字符时立即精简或归档。
- 每次会话结束更新 HANDOFF 的 next action。
